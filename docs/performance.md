# Производительность

Измерения нагрузки ещё не выполнялись. Цели из ТЗ: 2 vCPU, 4 ГБ RAM, 10 000 операций; p95 чтения до 500 мс, перевода до 1 с при 10 клиентах. Это не подтверждённые показатели.

Перед публикацией результатов укажите CPU/RAM, версию PostgreSQL, размер базы, число API workers, инструмент, длительность, RPS, p50/p95/p99 и долю ошибок. Подготовка данных и прогрев не входят в измерение. Ошибки недостатка средств учитывайте отдельно от серверных ошибок.

Конкурентные pytest проверяют целостность, а не пропускную способность. Согласования одной компании дополнительно сериализуются блокировкой владельца: это осознанный компромисс MVP. Для больших объёмов потребуется пересмотр гранулярности блокировок с сохранением безопасного отзыва ролей.
